# 在 iPhone 上定时暂停播放

1. 在「快捷指令」中创建一个快捷指令，添加控制媒体播放的动作，将模式明确设为「暂停」。
2. 在「自动化」中新建按时间触发的自动化，设定需要的时刻并选择「立即运行」，动作选为运行刚创建的快捷指令。
3. 有多个时刻时，为每个所需时刻创建自动化，复用同一个快捷指令，然后核对自动化列表。

2026-11-16 使用串口 USB HID 点击和滚轮完成过这套设置。手机解锁、测试音频正在播放时，定时触发后约 1.9 秒内观测到暂停。音频已暂停时再次运行，仍保持暂停。尚未验证锁屏触发；快捷指令未加入运行状态检测或互斥，触发重叠时的行为也未验证。

历史 USB 控制实验见 [固件验证记录](../../hardware/hid_bridge/doc/usb-hid-validation.md)。
